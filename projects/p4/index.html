Abstract

This flagship project studies persistent 3D object tracking when both detections and observer motion are imperfect. It integrates cached 3D detections, ego-motion compensation, state prediction, data association, and track lifecycle management, then evaluates how detection and pose perturbations interact to create identity and localisation failures.

Problem

Research question. How robust is persistent 3D object tracking when both detections and the observer's own motion are uncertain?

The tracker is designed around cached detections so that temporal experiments remain repeatable and separable from detector training. The completed study must isolate detection error, pose error, association logic, lifecycle behaviour, and their interactions.

Method

  1. Cached 3D detections.Consume deterministic detections through a documented coordinate-frame and timestamp contract.
  2. Ego-motion compensation.Transform observations and track states consistently as the observer moves.
  3. Prediction and association.Predict object state, gate candidate matches, and solve assignment with explicit uncertainty assumptions.
  4. Track lifecycle.Handle initiation, confirmation, missed detections, recovery, and deletion while preserving identity.

Experiments

InputsCached 3D detections plus a documented pose source.
Perturbation protocolFixed detection-noise × pose-noise grid with deterministic seeds and units.
EvaluationTracking/association metrics, ablations, camera/BEV sequence diagnostics, and CPU profiling.
OutputsPrimary results, uncertainty grid, failure taxonomy, reproducibility package, report/preprint, and code when verified.
