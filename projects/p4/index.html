Overview

How robust is persistent 3D object tracking when both detections and the observer's own motion are uncertain?

This flagship project synthesises the capabilities built in P1–P3. It uses cached detections so that tracker experiments remain repeatable and separates detection error, ego-motion error, association logic, and lifecycle behaviour.
