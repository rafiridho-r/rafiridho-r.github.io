TL;DR. Reproduce a scaled PointPillars pipeline, verify clean performance, then quantify how sparsity, dropout, noise, and range degradation alter detection behaviour.

Overview

How does pillar-based 3D detection degrade under controlled point-cloud corruption and reduced observation quality?

The project prioritises understanding and robustness over leaderboard-scale training. Dataset size, backbone width, and training budget will be reduced to fit available compute while preserving the core pillar-based representation.

Evaluation plan

Clean baseline

Establish a reproducible scaled baseline before any robustness claim.

Severity curves

Report detection degradation as corruption severity increases, not just one corrupted operating point.

Representation diagnosis

Inspect whether failure is driven by missing pillars, distant objects, orientation, or sparse occupancy.

Compute profile

Report training/inference memory and latency appropriate to the scaled setup.
