TL;DR. Reproduce the CACF tracking mechanism from first principles, then test whether a more conservative context-update rule improves robustness under distractors and appearance change.

Overview

When does contextual information improve correlation-filter tracking, and when does context updating become brittle?

The project is intentionally narrow: a candidate-owned reproduction, a controlled context-update extension, and a failure-oriented evaluation. The goal is not to build a new end-to-end tracker stack.

Evaluation plan

Reproduction fidelity

Verify the implementation on a controlled subset using standard tracking metrics and deterministic evaluation.

Robustness

Stress distractors, occlusion, appearance change, and context-update failure modes with fixed protocols.

Ablation

Isolate the effect of the proposed context-update rule rather than changing multiple components at once.

Efficiency

Report CPU/runtime behaviour and keep the implementation feasible on limited hardware.
