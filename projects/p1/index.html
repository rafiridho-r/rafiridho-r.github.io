Abstract

This project studies context-aware correlation-filter tracking through a from-scratch reproduction followed by a controlled context-update extension. The objective is to separate implementation fidelity from the effect of the proposed update rule, then analyse drift, distractor capture, occlusion, and appearance-change failures under fixed evaluation protocols.

Problem

Research question. When does contextual information improve correlation-filter tracking, and when does context updating become brittle?

The scope is deliberately limited to tracking and optimisation fundamentals. A bare reproduction is not the final deliverable: the completed project must include a genuine extension, ablation, robustness tests, and a defensible failure taxonomy.

Method

  1. Target and search region.Define the target state, search region, and contextual regions for the current frame.
  2. Correlation response.Compute the response surface and inspect whether context suppresses or reinforces competing peaks.
  3. Context-update decision.Update target/context statistics only when the observation satisfies the chosen reliability criterion.
  4. State propagation and diagnosis.Propagate the track and record success, drift, distractor capture, recovery, and update-induced failures.

Experiments

ImplementationCandidate-owned baseline reproduction, followed by one controlled context-update extension.
EvaluationScaled public tracking sequences; deterministic protocol and standard tracking metrics.
RobustnessDistractors, occlusion, appearance change, and update instability.
OutputsQuantitative table, response-map diagnostics, ablation, failure cases, runtime, and code when verified.
