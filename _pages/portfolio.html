Evidence standard

What qualifies as a portfolio research project

The website is an evidence layer, not a substitute for research. A project is promoted only after its implementation, experiments, and limitations can be defended technically.

01

Algorithmic ownership

Core logic, derivations, design decisions, and tests are attributable and explainable—not merely assembled from an existing repository.

02

Controlled evaluation

Fixed protocols, quantitative metrics, robustness experiments, ablations where justified, and explicit failure analysis.

03

Reproducibility

Frozen configs, code commit, environment, dataset split, experiment identifiers, and result provenance accompany public claims.
