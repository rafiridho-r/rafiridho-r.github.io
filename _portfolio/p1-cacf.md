**Status:** Planned  
**Area:** Tracking / Optimisation

This project reproduces the core ideas of **Context-Aware Correlation Filters (CACF)** and develops a controlled extension focused on context-update robustness.

The main question is:

> When does contextual information improve correlation-filter tracking, and when does context updating become brittle?

The project is intended to establish strong foundations in visual tracking, optimisation, implementation ownership, controlled evaluation, and failure analysis.

Results, code, quantitative evaluation, and failure cases will be added when the project reaches the corresponding evidence milestone.
