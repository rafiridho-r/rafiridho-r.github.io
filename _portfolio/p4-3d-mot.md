**Status:** Flagship · Planned  
**Area:** Robust 3D Multi-Object Tracking / Visual Navigation

This flagship project studies persistent 3D object tracking under both imperfect detections and uncertain observer motion.

The main question is:

> How robust is persistent 3D object tracking when both detections and the observer's own motion are uncertain?

The project will integrate 3D detections, ego-motion compensation, persistent object state, data association, track lifecycle management, and controlled detection/pose uncertainty experiments.

The final public page will include quantitative results, ablations, robustness analysis, failure cases, reproducibility information, and code once those artefacts exist.
